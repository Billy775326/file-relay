# 后台文件管理

[文档导航](README.md) | [安全防护](security.md) | [API 参考](api.md)

使用 `ADMIN_TOKEN` 登录 `/admin`；配置过 `ADMIN_PATH` 时使用自定义入口。顶部在“文件管理 / 日志审计 / 安全防护”之间切换，齿轮打开设置，发送按钮在新标签页打开发送页。

## 概览与筛选

概览显示分享总数、当前有效、文件、文本、今日新增及存储卡片。R2 容量包含现有对象与上传预留；绑定 `fileKV` 时显示 KV 卡片，具体用量需另配[只读统计](kv-usage.md)。统计未配置或读取失败时显示状态，不把未知数据当作零。

列表可按有效、已过期、已取完及文件/文本筛选。搜索覆盖所有页，范围为列表文件名前 40 字符、口令与原始访客标识，不包含管理员备注或文件说明。筛选后从第一页开始，保留每页条数。

- 点击口令复制；点击文件名打开文件详情；点击上传来源查看来源。
- 文件类型显示为文件名旁的上标，文件名单行省略，悬停查看全名。
- 删除使用垃圾桶按钮，并要求确认；删除后的文件不可恢复。
- 文本分享显示摘要，不使用文件详情入口；公开查看文本会消耗取件次数。

## 文件详情与来源

| 弹窗 | 主要内容 | 常用操作 |
|---|---|---|
| 文件详情 | 完整文件名、文件说明、预览、大小、状态、取件次数、创建/过期时间 | 下载、编辑分享、查看来源 |
| 上传来源 | 访客标识/备注、自填称呼、请求出口 IP、大致属地、网络组织、浏览器、近期上传 | 保存备注、复制 IP、查看近期文件 |

文件说明与可读取的内容预览是两种信息；未填写的说明不显示空段落。详情不展示清理日期，清理规则在设置中管理。

来源备注按签名访客标识关联新旧分享；来源不等于实名身份。IP 属地是出口位置，浏览器信息由客户端自报，不应据此证明好友身份。[来源识别范围](upload-sources.md#识别范围)。

### 管理员下载

管理员下载和预览不消耗公开取件次数。过期或次数用完的文件只要仍在存储中，就可下载；公开取件仍受原规则约束。

打开详情时检查存储状态：文件缺失时隐藏下载入口；读取异常或绑定缺失时提示“暂时无法确认”，仍可尝试下载。检查不读取整个文件，也不保证它在后续操作前不会被删除。

## 文件内容预览

文件详情在管理员权限下有限读取内容，不调用外部分析服务，也不把正文写入审计。不支持的类型或预览失败时，可下载原文件。

| 内容 | 当前范围 |
|---|---|
| UTF-8 文本与常见代码 | 最多前 64 KiB，截断时显示“部分内容”；HTML/脚本按纯文本显示 |
| CSV | 同一读取上限内最多 50 行、20 列；解析失败显示原文 |
| PNG、JPEG、静态 WebP | 最多 2 MiB、1600 万像素，检查文件头与尺寸 |
| PDF、Office、压缩包、可执行文件 | 暂不解析 |

动画 PNG/WebP、损坏图片、非 UTF-8 或含二进制控制字符的文本不预览。不提取软件版本、媒体时长或原始文件修改时间。

预览请求最长等待 15 秒；可重试，关闭弹窗会取消请求并释放图片临时地址。预览是片段或有限图片解码，不是安全扫描。

## 修改次数、有效期与状态

文件名 → **编辑分享**，修改已取次数、上限、过期时间或选择状态，点击“保存修改”后生效。取消不提交输入；时间按浏览器本地时区编辑，服务端保存 Unix 毫秒。

| 选择状态 | 表单联动 |
|---|---|
| 有效 | 已过期则延长至当前时间 7 天后；次数耗尽则增加上限，计数已达最大值时改为不限次 |
| 已过期 | 过期时间设为当前时间，保留原次数 |
| 已取完 | 有限分享把已取次数补至上限；不限次先建立至少为 1 的上限；原本过期则延长 7 天 |

联动值直接显示，允许继续编辑；最终状态须与次数和时间一致。已取次数可设 0–2,147,483,647，有限上限为 1–2,147,483,647。管理员修改不受访客永久/不限次限制，也不重新占用上传额度；不修改文件正文、口令、来源或创建时间。

如果打开弹窗后记录又被取件或修改，保存提示冲突并保留输入，可选择重新加载。D1 使用条件更新；KV 只能尽力检查，无法保证并发强一致。进入自动清理期、文件缺失或无法确认存储状态时不能编辑。审计保留修改前后规则，因此修改后的计数不等于未经调整的下载历史。

## 设置与翻页

齿轮设置直接排列三组项目；安全规则在独立页面管理。

| 设置 | 范围 | 保存位置 / 生效方式 |
|---|---|---|
| 文件每页条数 | 10 / 20 / 40，默认 20 | 当前浏览器，立即回到第一页 |
| 日志每页条数 | 20 / 50 / 100，默认 20 | 当前浏览器，立即回到第一页 |
| 过期后保留 | 0–3650 天，默认 30 | 服务端，点击该项保存，供后续清理使用 |
| 未备注访客每周文件数 | 0–1000，默认 5 | 服务端，点击该项保存 |

关闭设置不会提交未保存输入，退出登录位于设置底部。浏览器禁止本地存储时，页数偏好仅在本次会话使用并显示提示。

分页、总条数、每页条数和刷新位于各自列表上方；加载期间禁用翻页，迟到响应不覆盖新页。删除或清理使末页为空时退到有效页。文件管理不新增定时轮询，日志筛选条件在页面切换后保留。

## 日志审计

按分类、结果、日期或 IP/取件码/文件名/访客标识筛选；详情显示请求来源、状态和受控参数。时间按浏览器时区显示，日期包含当天。导出按钮导出当前筛选的全部保留记录为 JSON，未应用的筛选修改需先点击“筛选”。

| 分类 | 记录范围 |
|---|---|
| 登录日志 | 管理员登录成功、失败、退出 |
| 操作日志 | 设置、备注、编辑分享、来源查看、预览、管理员下载、删除、手动/Bearer 清理、导出 |
| 上传日志 | 文件直传/分片完成、文本发送结果；初始化/分片/完成失败阶段；主动取消已有会话 |
| 取件日志 | 查看分享、公开下载的成功或失败，含错误口令、过期、次数用尽、文件缺失 |
| 安全事件 | 新自动封禁、后台规则/名单操作、上传/取件的 IP、地区及限流拦截 |

上传配额和分享权限限制仍在上传日志中标为“已拦截”。正常初始化、成功分片及重复取消不单独新增日志；分片以完成分享作为成功记录。查看文件信息与真正下载是不同操作。

重复失败和公开拦截按固定 **5 分钟**窗口、来源 IP、方法、操作、阶段与原因合并，必要时区分有效上传会话。不同无效口令或不存在的会话不会各占一行。表格显示合并次数，详情包含首次/最近时间及最后一次请求的信息；日期筛选按最近发生时间，次数表示请求数，不是用户数。新触发的自动封禁单独保留；登录封禁后的重复重试仍不逐条记录。

审计自动使用 R2，否则使用 D1；纯 KV 明确显示未启用。保留最近 **30 天、最多 1,000 条**，后续写入剔除过期或最旧条目。包含文件名快照、请求出口 IP、属地、客户端标识等排查线索，不保存令牌、Cookie、任意请求正文、备注全文或文件内容。仅管理员能读取或导出。

以下边界需区分：

- 日志从功能上线后开始，不补造历史；普通页面访问、列表刷新、自动 Cron/首页清理不在审计范围。
- 未到达 Worker 的网络错误、Cloudflare 边缘拦截、未通知服务端的浏览器退出无法记录。
- 下载成功表示服务端开始返回文件流，不能证明浏览器保存完成。
- 共用管理令牌不能区分不同管理员；签名访客和 User-Agent 也不代表真实身份。
- 审计写入与业务不是同一事务。日志故障不重做已完成操作；后台提示未保存时，检查存储，缺失日志不能自动恢复。

日志会消耗存储和读写额度，聚合并不免除这些开销，也不提供不可篡改的合规归档保证。[接口筛选参数](api.md#日志审计) · [存储与回退](operations.md#更新已有部署)。

## 登录防护

进入“安全防护”查看和解封 IP。默认同一 IP 在任意连续 10 分钟内失败 5 次，封禁新登录 30 分钟；已有管理员会话仍可管理，不被注销。

这是站点内的类似 Fail2ban 功能，不运行 Fail2ban 守护进程。上传/取件也有独立规则，地区封禁禁止作用于后台登录。[完整规则、允许名单及误封处理](security.md)。

## 未备注访客限制

未备注访客默认每周 **5 次文件上传**；后台可改 0–1000，0 暂停新文件上传。所有访客共用全局大小上限，R2 默认 9.9 GB，KV 最多 25 MiB，不再单独限制访客 100 MB。

- 周额度按北京时间周一 00:00 重置，同时校验签名访客标识与请求 IP，任一耗尽即拒绝。
- 参数/权限检查通过并接纳后计一次；取消、容量不足、后续失败和删除均不退回。分片与完成不重复计次。
- 未备注访客不能创建永久或不限次分享，文本不占文件周额度。
- 添加非空管理员备注会解除周次数限制，并允许永久/不限次分享；清空后恢复限制，原计数不清零，已有分享不追溯修改。
- 备注不解除全局大小、桶容量或安全规则。KV 传播可能延迟，分片后续请求仍复核归属和当前权限。

配额优先由 R2、否则 D1 条件写入。纯 KV 不接受未备注访客文件，可先提交限时限次文本供管理员备注。清 Cookie 或单独换 IP 不会恢复另一维度额度，但同时更换两者仍可能绕过，不能当作身份验证系统。

## 过期保留天数

“设置 → 分享规则 → 过期后保留”默认 **30 天**，可设 **0–3650 整数天**。0 表示过期后即可进入清理范围，保存本身不删除文件。

依据为“过期时间 + 保留天数”，新设置适用于已有和后续过期记录；永久分享、仅次数耗尽不单独清理。保留期内仍占容量，管理员可主动删除。遗留上传会话另按 `SESSION_TTL_MS` 清理。

实际删除依赖下一次成功的 Cron、首页或外部定时任务；Pages 无访问不会自行触发首页清理。[清理配置](deployment.md#清理配置)。

## 升级与存储

设置保存到 KV，未绑定 KV 时使用 D1 `app_settings`；旧库首次保存时按需创建，不覆盖分享。设置损坏时停止清理，避免把错误误当作 0 天。

已有 D1 来源字段、审计新分类和安全状态的兼容边界见[升级与回退](operations.md#更新已有部署)。不要通过删表、删桶或重置容量台账排障。

## 管理接口

完整路径与字段集中在 [API 参考](api.md#管理文件与来源)，包括文件/来源、设置、清理、日志和安全规则。文件详情接口仍返回诊断用 `cleanupAfter` 等字段，界面不显示清理日期。

## 验证

开发者按改动选择 `test:admin-layout`、`test:admin-filters`、`test:preview`、`test:admin-download`、`test:share-edit`、`test:audit`、`test:security`、`test:upload-policy` 和 `test:retention`。环境和构建前提见[开发指南](development.md#检查与测试)。本地模拟器或界面测试通过不等于已在生产存储验收。
