## 三个容易混淆的区别

- **文件详情与上传来源**：文件详情回答“文件是什么、如何取件”，来源弹窗回答“请求来自哪里、关联了哪个访客”；来源线索不等于实名身份。
- **来源记录与日志审计**：近期上传只列出同一访客仍保留的分享；日志记录请求结果，包含失败和拦截，最多保留最近 30 天的 1,000 条。
- **容量与免费额度**：R2 的 9.99 GB 是项目当前桶的上传阈值；KV 卡片是命名空间日峰值；二者都不是整个 Cloudflare 账户的剩余账单额度。

## 文档中的约定

所有命令默认在仓库根目录执行；示例域名、IP、取件码、文件和令牌均为示意。MB / GB 使用十进制，MiB / GiB 使用二进制。接口时间为 Unix 毫秒，后台时间按浏览器时区显示，访客周额度按北京时间周一重置。

`npm run build:pages` 与 `npm run build:single` 只构建；`npm run deploy` 会发布。Git 集成 Pages 的生产分支推送也会触发部署。验证命令与验收范围见[开发指南](development.md#检查与测试)，文档中的操作示例不代表已在你的生产资源上执行。
